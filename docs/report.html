🛡️ OMARCHY SEC

Arquitectura Empresarial de EDR/XDR & Respuesta Autónoma con IA en Arch Linux
v1.0.0 · Production Ready

1. Resumen Ejecutivo

Omarchy Sec es una plataforma de seguridad agnóstica de grado empresarial y respuesta autónoma a incidentes diseñada específicamente para estaciones de trabajo Omarchy Linux (Arch Linux + Hyprland).

Permite integrar y monitorear agentes corporativos de CrowdStrike Falcon, Microsoft Defender (MDE), SentinelOne, Palo Alto Cortex XDR y Wazuh, resolviendo el desafío de compatibilidad en distribuciones rolling-release y garantizando que los equipos reporten telemetría en tiempo real a las consolas centrales del SOC corporativo bajo un estricto modelo Zero Trust.

Pilares Clave:
  • Agnóstico & Multi-Sensor: Detecta y unifica el monitoreo de cualquier sensor EDR instalado sin configuraciones complejas.
  • Respuesta Autónoma con IA ("Call Agent"): Conexión en tiempo real con la API de Wazuh (:55000) e historial forense para investigación y contención activa (kill processes, firewall isolate).
  • Zero Trust Microsegmentation: Telemetría saliente exclusiva (Egress TLS/443); 0 puertos abiertos requeridos en la estación de trabajo.
  • DevSecOps Verified: 100% aprobado en SAST, IaC, Secrets scanning, SCA y DAST.

4. Mecanismo de Respuesta Autónoma con IA ("Call Agent")

A diferencia de los paneles tradicionales que solo ofrecen indicadores estáticos, Omarchy Sec incorpora un puente interactivo directo entre el motor EDR y el Agente de IA de Omarchy:

Flujo de Operación del Agente SOC:

  1. Autenticación con la API REST (:55000): Genera tokens JWT dinámicos para consultar el estado del endpoint, FIM (Syscheck) y evaluaciones de configuración de seguridad (SCA).
  2. Volcado de Telemetría Forense: Inyecta las últimas alertas registradas en alerts.json, sockets abiertos (ss -tuln) y procesos de alto consumo.
  3. Capacidad de Contención Inmediata: El agente puede aislar direcciones IP maliciosas mediante ufw/nftables, matar procesos sospechosos (kill) y sugerir reversión de archivos vía snapshots de Btrfs/Snapper.
