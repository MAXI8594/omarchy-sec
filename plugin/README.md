# Wazuh Security Plugin for Omarchy Shell

A native Omarchy status bar widget and popout panel for monitoring Wazuh EDR & XDR security health, real-time alerts, and quick access to the SOC dashboard.

## Features
* 🛡️ Real-time health indicator (🟢 Protected, 🟡 Warning, 🔴 Threat/Stopped)
* 📊 Popout details panel with endpoint metrics and quick actions
* 🌐 One-click access to the local SOC dashboard
* 🔄 Restart / Refresh agent service directly from the UI

## Runtime Contract
* Kind: `bar-widget`
* Entry point: `BarWidget.qml`
* Details surface: `Panel.qml`
